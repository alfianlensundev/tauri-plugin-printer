## Default Permission

Read-only access to installed printers, capabilities, and print jobs

#### This default permission set includes the following:

- `allow-get-printers`
- `allow-get-printer`
- `allow-get-default-printer`
- `allow-get-printer-capabilities`
- `allow-get-jobs`
- `allow-get-job`
